# 天机盘 美术资源需求文档

> 本文档供美术同事参考，网站当前使用纯 CSS + Unicode 实现基础视觉效果。
> 以下资源为可选增强项，按优先级排列。

---

## P0 — 必要

### 1. Favicon
- **用途**: 浏览器标签页图标
- **规格**: `.ico` 或 `.png`，16x16 / 32x32 / 180x180
- **建议**: 用"天"字做成印章风格的小图标，朱砂红底白字
- **占位位置**: `public/favicon.ico`

### 2. OG Image（分享预览图）
- **用途**: 社交媒体/聊天分享链接时的预览图
- **规格**: 1200x630px，`.png` 或 `.jpg`
- **建议**: 水墨山水背景 + "天机盘" 大字 + 副标题"诸位道友，请下注"
- **占位位置**: `public/og.png`（需在 `layout.tsx` metadata 中引用）

---

## P1 — 推荐

### 3. 灵石图标
- **用途**: 替代当前的 Unicode 💎，用于余额显示和下注金额
- **规格**: SVG 格式，48x48（可缩放）
- **建议**: 一颗古风玉石/灵石，半透明翡翠绿 + 金色光晕
- **风格参考**: 可参考修仙小说插图中的灵石描绘
- **占位位置**: `public/icons/spirit-stone.svg`

### 4. 空状态插画
- **用途**: 暂无盘口时显示的插画
- **规格**: 400x300px，`.svg` 或 `.png`（透明背景）
- **建议**: 一个修士背对观者，面对云雾缭绕的山峰，带一把剑
- **占位位置**: `public/illustrations/empty-market.png`

---

## P2 — 可选增强

### 5. 页面顶部水墨山峦装饰
- **用途**: 首页顶部装饰性背景
- **规格**: 横幅式，1920x200px，`.svg`（半透明，渐变淡出）
- **建议**: 简约水墨远山轮廓，只用墨色，不抢主体
- **占位位置**: `public/decorations/mountains.svg`

### 6. 印章素材
- **用途**: 排行榜前三名、已结算状态等标记
- **规格**: SVG，多尺寸（48/64/96px）
- **建议**: 传统印章风格，朱砂红
- **需要**: "胜"字章、"天机"字章
- **占位位置**: `public/icons/seal-win.svg`, `public/icons/seal-tianji.svg`

## 字体

- 标题: **Ma Shan Zheng**（毛笔书法体）
- 正文: **Noto Serif SC**（宋体）

## 注意事项

- 所有美术资源建议使用**水墨/工笔画风格**，避免现代卡通或扁平设计
- 色彩克制，以墨色为主，点缀朱砂和金色
- 留白很重要，不要填充太满
- 所有图标建议提供 SVG 格式以保证清晰度
